# 🛒 E-Commerce Sales Dashboard

This project provides an interactive Power BI dashboard to analyze e-commerce sales data. It highlights key business insights related to sales, profit, quantity, customer performance, product categories, and payment methods.

---

## 📊 Project Overview

This project analyzes e-commerce sales data using Power BI to identify trends in sales, profit, product categories, customer performance, and payment methods.

- Total sales, profit, quantity, and average order value (AOV)
- Monthly profit trends
- State-wise sales performance
- Category-wise product quantity
- Customer-wise sales performance
- Payment mode distribution
- Sub-category-wise profit

---

## 📦 About the Dataset

The project uses two CSV files:

**Orders.csv:** Contains 500 orders with order date, customer name, state, and city.

**Details.csv:** Contains 1,500 order-detail records with amount, profit, quantity, category, sub-category, and payment mode.

Both files are connected using the Order ID column.

---

## 🔧 Technologies Used

**Power BI –** Dashboard creation and data visualization

**Power Query -** Data cleaning and transformation

**Excel / CSV -** Dataset storage and preparation

---

## 📈 Dashboard Features

- KPI cards for total sales, profit, quantity, and average order value (AOV).
- Monthly profit analysis to identify profit trends.
- State-wise sales comparison.
- Category-wise quantity distribution.
- Customer-wise sales analysis.
- Payment mode distribution.
- Sub-category-wise profit comparison.
- Interactive filters for exploring sales data.

---

## 🎯 Objective

To transform e-commerce sales data into meaningful visual insights, understand business performance, and support data-driven decision-making.
